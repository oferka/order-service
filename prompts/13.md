Create integration tests for the Order API using @SpringBootTest and Testcontainers:

1. Create an abstract BaseIntegrationTest class:
    - Use a shared static PostgreSQLContainer (start in static block, not @Testcontainers — avoids per-class restarts)
    - Use @DynamicPropertySource to override spring.datasource.url, username, password
    - Inject JwtService, CustomerRepository, OrderRepository, OrderItemRepository, ObjectMapper
    - Utility methods:
      - createTestCustomer() — calls createTestCustomerWithRole(ROLE_USER)
      - createTestCustomerWithRole(CustomerRole) — saves Customer directly via repository with a dummy passwordHash; role field must be set
      - generateTokenFor(Customer) — calls jwtService.generateToken with the customer's id, email, and role
      - buildCreateOrderRequest(UUID customerId) — returns a valid CreateOrderRequest
      - createOrderViaApi(CreateOrderRequest) — posts via MockMvc without explicit auth header (for use with @WithMockUser)
      - createOrderViaApi(CreateOrderRequest, String token) — posts via MockMvc with Authorization: Bearer header

2. OrderApiIntegrationTest extends BaseIntegrationTest:
    - Annotate the class with @WithMockUser(roles = "ADMIN") — tests run as admin so ownership checks are bypassed
    - test_createOrder_returns201: POST a valid CreateOrderRequest, verify 201 status, verify response body has orderNumber and status CREATED
    - test_createOrder_invalidRequest_returns400: POST with empty items, verify 400 with validation errors
    - test_getOrder_returns200: create an order, then GET by orderNumber, verify full response structure
    - test_getOrder_notFound_returns404: GET with non-existent orderNumber
    - test_updateStatus_validTransition: create order, PATCH to CONFIRMED, verify 200
    - test_updateStatus_invalidTransition_returns409: create order, PATCH to DELIVERED (skipping CONFIRMED/SHIPPED), verify 409
    - test_listOrders_withPagination: create 15 orders, GET with page=0&size=5, verify pagination fields

3. AuthorizationIntegrationTest extends BaseIntegrationTest:
    Use createTestCustomer() + generateTokenFor() to obtain real JWTs. No @WithMockUser.

    GET /api/v1/orders/{orderNumber}:
    - should_return200_when_ownerRequests
    - should_return403_when_nonOwnerRequests
    - should_return200_when_adminRequests
    - should_return401_when_unauthenticated

    GET /api/v1/orders:
    - should_returnOnlyOwnOrders_when_regularUserRequests
    - should_ignoreCustomerIdFilter_when_regularUserPassesAnotherUsersId
    - should_returnAllOrders_when_adminRequests

    PATCH /api/v1/orders/{orderNumber}/status:
    - should_return403_when_regularUserUpdatesStatus
    - should_return200_when_adminUpdatesStatus

    DELETE /api/v1/orders/{orderNumber}:
    - should_return204_when_ownerCancels
    - should_return403_when_nonOwnerCancels
    - should_return204_when_adminCancels

    POST /api/v1/orders:
    - should_return403_when_userCreatesOrderForAnotherCustomer
    - should_return201_when_adminCreatesOrderForAnyCustomer

    GET /api/v1/customers/{id}:
    - should_return200_when_userRequestsOwnProfile
    - should_return403_when_userRequestsAnotherProfile
    - should_return200_when_adminRequestsAnyProfile

    GET /api/v1/customers/by-email:
    - should_return403_when_regularUserSearchesByEmail
    - should_return200_when_adminSearchesByEmail

4. OrderEventListenerIntegrationTest extends BaseIntegrationTest:
    Use @MockitoSpyBean (Spring Boot 4.x — NOT @SpyBean) on OrderEventListener to verify event firing.
    Do NOT annotate the test class or methods with @Transactional — @TransactionalEventListener(AFTER_COMMIT) never fires inside a test-managed transaction that never commits.

    - should_fireOnOrderCreated_when_orderSavedSuccessfully:
      Create a customer + token, POST a valid order, verify orderEventListener.onOrderCreated() was called exactly once.
    - should_notFireOnOrderCreated_when_transactionRollsBack:
      Use an admin token with a non-existent customer UUID — the request enters the transaction, hits EntityNotFoundException, rolls back.
      Verify orderEventListener.onOrderCreated() was never called.
    - should_fireOnOrderStatusChanged_when_statusUpdatedSuccessfully:
      Create an order as a regular user, PATCH its status as admin, verify orderEventListener.onOrderStatusChanged() was called exactly once.

Use MockMvc with content type APPLICATION_JSON. Use ObjectMapper to serialize request bodies.
Verify JSON paths using jsonPath assertions.
