Create unit tests for OrderService and CustomerService using JUnit 5 and Mockito:

## OrderServiceImplTest

Use @ExtendWith(MockitoExtension.class). Use @Mock for dependencies (including SecurityUtils) and @InjectMocks for OrderServiceImpl.
In @BeforeEach, stub SecurityUtils.isAdmin() to return true using lenient().when(...) — unit tests run as admin so ownership checks are bypassed; authorization rules are covered by AuthorizationIntegrationTest.

1. createOrder_Success: mock the repo and mapper, verify order is saved with correct fields, verify event is published
2. createOrder_CustomerNotFound: verify EntityNotFoundException is thrown
3. updateOrderStatus_ValidTransition: test CREATED → CONFIRMED works
4. updateOrderStatus_InvalidTransition: test DELIVERED → CREATED throws IllegalStateException
5. cancelOrder_Success: test CREATED → CANCELLED — order builder must include a Customer (required for ownership check)
6. cancelOrder_AlreadyDelivered: verify it throws on DELIVERED → CANCELLED — order builder must include a Customer
7. listOrders_WithFilters: verify Specification-based query is called with correct params

## CustomerServiceImplTest

Use @ExtendWith(MockitoExtension.class). @Mock: CustomerRepository, CustomerMapper, PasswordEncoder, SecurityUtils. @InjectMocks: CustomerServiceImpl.
Use @Nested classes grouped by method. Use AssertJ assertions.

### CreateCustomer
1. should_createCustomer_when_emailIsUnique: verify password hash is applied, customer is saved and response returned
2. should_throwIllegalStateException_when_emailAlreadyExists: verify repository.save is never called
3. should_useGenericMessage_when_emailAlreadyExists: verify error message does NOT contain the email (anti-enumeration)

### VerifyCredentials
4. should_returnCustomerResponse_when_credentialsAreValid
5. should_throwBadCredentialsException_when_emailNotFound: message = "Invalid credentials"
6. should_throwBadCredentialsException_when_passwordIsWrong: message = "Invalid credentials"
7. should_useSameErrorMessage_for_unknownEmailAndWrongPassword: both failure paths return identical message (anti-enumeration)

### GetCustomerById
8. should_returnCustomer_when_callerIsOwner: securityUtils.getCurrentUserId() returns same id
9. should_returnCustomer_when_callerIsAdmin: securityUtils.isAdmin() returns true, getCurrentUserId not called
10. should_throwAccessDeniedException_when_callerIsNonOwner: verify repository.findById is never called
11. should_throwEntityNotFoundException_when_customerNotFound

### GetCustomerByEmail
12. should_returnCustomer_when_emailExists
13. should_throwEntityNotFoundException_when_emailNotFound
