Create the following Spring application events and listeners:

1. OrderCreatedEvent — contains the orderId, orderNumber, customerId, totalAmount, timestamp

2. OrderStatusChangedEvent — contains orderId, orderNumber, previousStatus, newStatus, timestamp

3. OrderEventListener class annotated with @Component:
  - @EventListener for OrderCreatedEvent: log the event details at INFO level. Add a TODO comment for "send order confirmation email" and "notify inventory service".
  - @TransactionalEventListener(phase = AFTER_COMMIT) for OrderStatusChangedEvent: log the status change. Add TODO for "push notification to customer".

This demonstrates how we decouple side effects from core business logic.
