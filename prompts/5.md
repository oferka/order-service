Create request and response DTOs in the dto package:

1. CreateOrderRequest:
   - customerId (UUID, @NotNull)
   - items (List<OrderItemRequest>, @NotEmpty, @Valid)
   - shippingAddress (AddressRequest, @NotNull, @Valid)

2. OrderItemRequest:
   - productId (@NotBlank)
   - productName (@NotBlank)
   - quantity (@Min(1))
   - unitPrice (@NotNull, @DecimalMin("0.01"))

3. AddressRequest:
   - street, city, state, zipCode, country — all @NotBlank

4. UpdateOrderStatusRequest:
   - status (@NotNull OrderStatus)

5. OrderResponse:
   - id, orderNumber, status, customerEmail, customerName
   - items (List<OrderItemResponse>)
   - shippingAddress
   - totalAmount
   - createdAt, updatedAt
6. OrderItemResponse:
   - id, productId, productName, quantity, unitPrice, subtotal

7. PagedResponse<T>: a generic wrapper with content, page, size, totalElements, totalPages

Now create MapStruct mappers:
- OrderMapper (interface, @Mapper(componentModel = "spring"))
   - map CreateOrderRequest → Order entity (ignore id, orderNumber, status, totalAmount, createdAt, updatedAt)
   - map Order entity → OrderResponse (map customer.email → customerEmail, customer.fullName → customerName)
   - map OrderItem entity → OrderItemResponse
   - map list of OrderItem entities → list of OrderItemResponse
