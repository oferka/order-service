Create request and response DTOs in the dto package:

1. CreateOrderRequest:
   - customerId (UUID, @NotNull)
   - items (List<OrderItemRequest>, @NotEmpty, @Valid)
   - shippingAddress (AddressRequest, @NotNull, @Valid)

2. OrderItemRequest:
   - productId (@NotBlank, @Size(max = 255))
   - productName (@NotBlank, @Size(max = 255))
   - quantity (@Min(1), @Max(10_000))
   - unitPrice (@NotNull, @DecimalMin("0.01"))

3. AddressRequest:
   - street (@NotBlank, @Size(max = 255))
   - city (@NotBlank, @Size(max = 100))
   - state (@NotBlank, @Size(max = 100))
   - zipCode (@NotBlank, @Size(max = 20))
   - country (@NotBlank, @Size(max = 100))

4. UpdateOrderStatusRequest:
   - status (@NotNull OrderStatus)

5. OrderResponse:
   - id, orderNumber, status, customerEmail, customerName
   - items (List<OrderItemResponse>)
   - shippingAddress
   - totalAmount
   - createdAt, updatedAt
6. OrderItemResponse:
   - id, productId, productName, quantity, unitPrice, subtotal

7. PagedResponse<T>: a generic wrapper with content, page, size, totalElements, totalPages

8. CreateCustomerRequest:
   - email (@NotBlank, @Email, @Size(max = 255))
   - password (@NotBlank, @Size(min=8, max=128)) — plain text; the service layer will hash it
   - fullName (@NotBlank, @Size(max = 255))
   - phone (nullable, @Size(max = 50))

9. CustomerResponse:
   - id, email, fullName, phone, role (CustomerRole), createdAt, updatedAt
   - Never include passwordHash

10. TokenRequest:
    - email (@NotBlank, @Email)
    - password (@NotBlank)

11. TokenResponse:
    - token (String)

Now create MapStruct mappers:
- OrderMapper (interface, @Mapper(componentModel = "spring"))
   - map CreateOrderRequest → Order entity (ignore id, orderNumber, status, totalAmount, createdAt, updatedAt)
   - map Order entity → OrderResponse (map customer.email → customerEmail, customer.fullName → customerName)
   - map OrderItem entity → OrderItemResponse
   - map list of OrderItem entities → list of OrderItemResponse
- CustomerMapper (interface, @Mapper(componentModel = "spring"))
   - map CreateCustomerRequest → Customer entity (ignore id, passwordHash, role, createdAt, updatedAt) — role defaults to ROLE_USER via @Builder.Default
   - map Customer entity → CustomerResponse (role is mapped automatically)
