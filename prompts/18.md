Create .github/workflows/ci.yml with a complete CI pipeline:

Trigger: push to main, pull requests to main

Jobs:

1. build-and-test:
    - Runs on: ubuntu-latest
    - Services: postgres:18 (for integration tests)
    - Steps:
        - Checkout code
        - Set up Java 25 (temurin)
        - Cache Maven dependencies
        - Run: mvn clean verify -Pstaging (which runs unit + integration tests)
        - Upload test reports as artifacts
        - Upload JaCoCo coverage report

2. docker-build (needs: build-and-test, only on main branch push):
    - Set explicit permissions: contents: read, packages: write
      (GITHUB_TOKEN defaults to packages: read; write is required to push to GHCR)
    - Log in to GitHub Container Registry (ghcr.io)
    - Build Docker image with tag: ghcr.io/${{ github.repository }}:${{ github.sha }} and :latest
    - Push both tags

3. deploy-staging (needs: docker-build, only on main branch push):
    - Placeholder step: echo "Deploy to staging Kubernetes cluster"
    - Add a comment: "Replace with kubectl apply or Helm upgrade command"
