Create integration tests for the Order API using @SpringBootTest and Testcontainers:

1. Create an abstract BaseIntegrationTest class:
    - Use @Testcontainers with a shared PostgreSQL container (PostgreSQLContainer from Testcontainers)
    - Use @DynamicPropertySource to override spring.datasource.url, username, password
    - Use @AutoConfigureMockMvc
    - Include a utility method to create a test customer in the DB via CustomerRepository

2. OrderApiIntegrationTest extends BaseIntegrationTest:
    - test_createOrder_returns201: POST a valid CreateOrderRequest, verify 201 status, verify response body has orderNumber and status CREATED
    - test_createOrder_invalidRequest_returns400: POST with empty items, verify 400 with validation errors
    - test_getOrder_returns200: create an order, then GET by orderNumber, verify full response structure
    - test_getOrder_notFound_returns404: GET with non-existent orderNumber
    - test_updateStatus_validTransition: create order, PATCH to CONFIRMED, verify 200
    - test_updateStatus_invalidTransition_returns409: create order, PATCH to DELIVERED (skipping CONFIRMED/SHIPPED), verify 409
    - test_listOrders_withPagination: create 15 orders, GET with page=0&size=5, verify pagination fields

Use MockMvc with content type APPLICATION_JSON. Use ObjectMapper to serialize request bodies.
Verify JSON paths using jsonPath assertions.
