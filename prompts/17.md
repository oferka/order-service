Implement JWT security:

1. SecurityConfig class:
   - Annotate with @EnableMethodSecurity to enable @PreAuthorize on service methods
   - Disable CSRF (stateless API)
   - Permit all requests to: /api/v1/auth/**, /api/v1/customers (POST only, for self-registration), /actuator/health, /actuator/info, /v3/api-docs/**, /swagger-ui/**
   - All other endpoints require authentication
   - Use stateless session management
   - Register a JwtAuthenticationFilter before UsernamePasswordAuthenticationFilter
   - Expose a PasswordEncoder bean: return new BCryptPasswordEncoder()

Also create a SecurityUtils @Component in the security package:
   - getCurrentUserId(): UUID — parses the JWT principal (a String) as UUID from SecurityContextHolder
   - isAdmin(): boolean — returns true if the authenticated user has the ROLE_ADMIN authority
   - Both methods read from SecurityContextHolder.getContext().getAuthentication()
   - isAdmin() must be checked BEFORE getCurrentUserId() in ownership checks so that @WithMockUser(roles = "ADMIN") in tests never triggers UUID parsing of non-UUID principals

2. JwtService:
   - generateToken(String userId, String email, List<String> roles): create a JWT with:
      - subject: userId
      - claims: email, roles
      - issued at: now
      - expiration: 24 hours
      - signed with HMAC-SHA256 using a secret from application.yml (jwt.secret)
   - validateToken(String token): parse and validate, return Claims
   - getUserIdFromToken(String token): extract subject

3. JwtAuthenticationFilter (extends OncePerRequestFilter):
   - Extract token from Authorization: Bearer <token>
   - Validate and set SecurityContext with a UsernamePasswordAuthenticationToken
   - If invalid, log at WARN level with method, URI, and exception message (no token value): log.warn("JWT validation failed for request {} {}: {}", method, uri, e.getMessage()), then continue the chain without setting context (let Spring Security return 401)

4. AuthController (/api/v1/auth):
   - POST /token: accept @Valid @RequestBody TokenRequest (email + password). Delegate entirely to AuthService.authenticate(request) and return TokenResponse. No business logic in the controller.

5. Update the GlobalExceptionHandler to handle AccessDeniedException (403) and AuthenticationException (401)

6. OpenApiConfig class:
   - Declare a Bearer JWT security scheme named "bearerAuth" using @SecurityScheme
   - Apply it globally via @OpenAPIDefinition with @SecurityRequirement(name = "bearerAuth")
   - This enables the Authorize button in Swagger UI so users can authenticate and test protected endpoints
