Create the following REST controllers with full OpenAPI/Swagger annotations (@Tag, @Operation, @ApiResponse):

1. OrderController (base path /api/v1/orders):
    - POST / — create a new order. Accept @Valid @RequestBody CreateOrderRequest. Return 201 with OrderResponse.
    - GET /{orderNumber} — get order by order number. Return 200 with OrderResponse.
    - GET / — list orders with pagination (page, size, sort params). Optional filter by status and customerId. Return 200 with PagedResponse<OrderResponse>.
    - PATCH /{orderNumber}/status — update order status. Accept @Valid @RequestBody UpdateOrderStatusRequest. Return 200 with OrderResponse.
    - DELETE /{orderNumber} — cancel an order (soft cancel by transitioning to CANCELLED). Return 204.

2. CustomerController (base path /api/v1/customers):
    - POST / — create customer. Accept @Valid @RequestBody CreateCustomerRequest (includes password). Return 201 with CustomerResponse and Location header.
    - GET /{id} — get customer by ID. Return 200 with CustomerResponse.
    - GET /by-email?email= — get customer by email. Return 200 with CustomerResponse.

3. AuthController (base path /api/v1/auth):
    - POST /token — authenticate a customer. Accept @Valid @RequestBody TokenRequest (email + password). Delegate entirely to AuthService.authenticate(request). Return 200 with TokenResponse.
    - The controller must contain NO business logic — no direct JwtService or CustomerRepository access.

Use ResponseEntity for all return types. Inject services via constructor injection.
