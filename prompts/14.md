Create a dedicated unit test class OrderStatusTransitionTest:

Test every valid transition:
- CREATED → CONFIRMED ✓
- CREATED → CANCELLED ✓
- CONFIRMED → SHIPPED ✓
- CONFIRMED → CANCELLED ✓
- SHIPPED → DELIVERED ✓

Test every invalid transition:
- CREATED → SHIPPED ✗
- CREATED → DELIVERED ✗
- CONFIRMED → CREATED ✗
- CONFIRMED → DELIVERED ✗
- SHIPPED → CREATED ✗
- SHIPPED → CONFIRMED ✗
- SHIPPED → CANCELLED ✗
- DELIVERED → any other status ✗
- CANCELLED → any other status ✗

Use @ParameterizedTest with @MethodSource or @CsvSource to avoid repetitive test methods.
Each invalid transition should throw IllegalStateException with a descriptive message.
