Create a docker-compose.yml that brings up the full observability stack:

1. order-service:
   - Build from the Dockerfile
   - Environment: spring.profiles.active=staging, DB connection params
   - Ports: 8080:8080
   - Depends on: postgres
   - Health check: curl actuator/health

2. postgres:
   - Image: postgres:16-alpine
   - Volume for data persistence
   - Init with a database named "orderdb"

3. prometheus:
   - Image: prom/prometheus:latest
   - Mount a prometheus.yml config that scrapes order-service at :8080/actuator/prometheus every 15s

4. grafana:
   - Image: grafana/grafana:latest
   - Port: 3000:3000
   - Mount a provisioning directory with:
      - Datasource config pointing to prometheus
      - A pre-built dashboard JSON for order-service with panels for:
        request rate, response time p50/p95/p99, JVM memory, order creation counter, active orders gauge

Include a Makefile with targets: build, up, down, logs, test
